# 色彩时代

根据 Edwin A. Abbott《Flatland》第一部第 8—10 节，以及使用者提供的《色彩时代：原著时间线与故事编排依据》改编。先让颜色成为日常生活，再让观众看见颜色如何改变身份辨认、引出平等诉求，最后被权力收走。

## 舞台与观看

全剧采用一个共用的检阅场。家族、街市、军阵与大会通过演员的站位和行动转换，不把同一场地说成真正切换了建筑。字幕是后世叙述，不让正方形成为数百年前事件的亲历者。对白是根据事件写的改编台词，不冒充原著引语。

故事的配色方案、配色模式和自定义颜色固定保存在自己的 `settings.json` 中，不读取游乐场保存的配置。各幕控制时期与人物是否染色。未染色时保留几何的明暗。无色的妇女和祭司穿过有色群众，避免把整个社会同时染色。结尾按搜查批次逐步剥去颜色，再回到全体无色。

原著阅兵的具体色值、法案的前红后绿保留在叙述中。画面按使用者选定的杜菲配色呈现，不强制覆盖为原著色值；阅兵通过真实转身显示各个边面，绝不把随机换色当作转身。

演员与群众缩编，代表阵营和世代，不与原著人数一一对应。早期家族在两代人之后退场，后期代表另有身份。战斗采用真实的二维接触与顶角击杀，死亡后边线散开并淡出，不展示血腥。普通退场与被击杀分开处理。

`settings.json` 完整固定当前画面的杜菲配色、随机组合、镜头与光学参数，其中散射范围为 128 身长，以看清跨度约 70 身长的扇形军阵。`coloring` 的基础值为真，各幕再覆盖有色与无色的时期。游乐场可以另行调参，两边互不读写用户配置。

全剧 14 幕，共 **3 分 46 秒**。点击章节即从该幕开头自动播放。以下逐幕段落保留完整编排意图，播放器字幕采用更短的表述，以配合加快后的节奏。

阅兵缩编为 **1,200 名士兵，24 圈、每圈 50 人的扇形阵列**，另有少量检阅人员。圆形使用同一 `Character` 的 32 边近似，十二边形使用 12 边；士兵使用已有的狭长三角形。只在阅兵幕显示大军阵，其他幕保持小规模群像。近处的检阅人员位于指挥官侧后方，留出面向军阵的观察通道。

## 每幕机位

跟随机位随关键角色的实际位置移动，偏移约一身长；邻居挡住机位时，就近避开身体。朝向由每幕确定，不随着被观察角色转身而突然旋转。俯视端正对地面，并把显示高度降为零，所有轮廓都在同一平面；切到居民一维后，从同一个观察点看出去。默认机位隐藏摄像机圆环、射线和位置标记；手动移动或重新选点后才显示，下一幕恢复默认机位。

| 幕 | 机位与朝向 |
| --- | --- |
| 颜色以前 | 固定在散落的普通居民前，面向自然走动的群体。 |
| 第一种颜色 | 跟随发明者，从他身边看家族染色和邻居让路。 |
| 一周、数月、一年 | 仍跟随发明者，向右前方看扩散的人群。 |
| 两代人以后 | 转到一位工匠身边，观看新一代的街市。 |
| 盛大的检阅 | 阅兵指挥官前方，向扇形军阵中央看。 |
| 我们为何不平等 | 革命领袖身边，面向聚拢、交谈与走动的工匠和士兵。 |

| 一年多的搜查 | 幸存工匠身边，观看搜查中的居民分批失色。 |
| 漫长的无色时代 | 留在同一位幸存者身边，面对继续走动的无色居民。 |

## 运动与接触

只有阅兵保持整齐的扇形编队。其他幕在故事数据中保存随机种子、散点范围和走动规则，加载时一次生成站位与弧线路径；每次播放仍能重现同一版编排。角色错开起步、停顿和转向，日常走动平缓加减速，冲锋快速加速。

各幕启用 `collision: true`。`move` 指定移动目标，`via` 是二次曲线的控制点，`easing` 使用 `smooth`、`ease-in` 或 `ease-out`。现有 Character 与 Rapier 决定实际位置、阻挡与偏转，身体不会直接穿过邻居。战斗中的进攻者使用 `interaction: "kill"`，实际顶角接触才触发死亡；其他时候使用 `touch`。物理按故事时间以每秒 60 步推进，暂停、跳幕与重播不受观看帧率影响，碎裂也随故事时间暂停。

第二幕的家庭染色间隔约 0.42 秒，仍依次表现奴仆、父亲、儿孙和发明者。第三幕普通居民的间隔约 0.11 秒，在约 4.5 秒内传至十二边形；搜查中的失色同样加快为短间隔的连续变化。

## 用规则编排群像

`story.json` 只单独定义 12 个具名人物，其余居民由 9 个 `groups` 模板生成，共 1,276 人。模板沿用现有 `Character` 类型，例如 `{"id":"soldier","type":"narrow-triangle","size":0.72,"count":24}`，生成 `soldier_1` 至 `soldier_24`。各幕的 `cast` 指定本幕出场的人物和群体；`{"group":"soldier","count":8}` 表示前八人。

动作中的 `actor` 指定一个人物，`actors` 可指定整组、若干组或上述部分群体。除关键冲锋、出口封锁等走位外，用以下规则代替逐人写坐标：

| 规则 | 用途 |
| --- | --- |
| `scatter: {bounds: [-8,8,-5,5], gap: 1.05}` | 在范围内随机取点，排除间距太近的位置；`avoid` 可留出通道。 |
| `wander: {radius: 2, step: [1.6,3], pause: [0.18,0.85]}` | 各自选择附近目标、曲线路径和停顿，以平缓加减速走动。需指定 `duration`。 |
| `fan: {rings: 24, radius: 18, gap: 0.95, angles: [210,330]}` | 生成 1,200 人的扇形军阵。 |
| `turnBy: 180` 与 `stagger: {interval: 0.14, batch: 50}` | 每 50 人一批，依次转半圈。 |
| `face: "revolt_leader"` 与 `duration` | 持续朝向指定主角的实际位置；目标可换成任意角色 ID，并不限于领袖。 |
| `sway: {angle: 8, period: 2.6}` 与 `duration` | 围绕当前朝向周期摆动，角度单位为度、周期单位为秒；不主动改变位置。 |

染色动作同样可用 `stagger` 错开时间，`from` 指定传播起点人物，按距离由近至远展开。`face` 在持续期间接管朝向；同时设置走动时，居民可以一边走一边看向主角。若希望看到摇摆，不在同一时段设置 `face`。

算法思路参考 Processing 的 [固定随机种子](https://processing.org/reference/randomSeed_)与 [正弦波](https://processing.org/examples/sinewave)：种子让随机编排可重现，正弦让摆动连续。散点采用带最小间距的随机采样，走动采用随机目标和二次曲线；不引入 Processing 运行库。所有规则最终展开为共用播放器的数据动作，碰撞仍由现有物理世界处理。

## 分幕

### 1. 颜色以前 · 8 秒

很久以前，平面国居民凭声音、触摸和几何明暗辨认彼此。形状也是身份：越多的边，往往意味着越高的地位。会辨认形状的知识，并不平等地属于每个人。

行动：不同形状散落在场内，以各自的节奏走弧线、停顿和转身；相遇时发生阻挡与偏转。所有人无色，不排成整齐队列。

### 2. 第一种颜色 · 14 秒

传说五边形 Chromatistes 发现了简单的颜料与染色方法。他先装饰房子，然后染了奴仆、父亲、儿子和孙辈，最后才染自己。邻居开始直接看出他的朝向，不必每次触摸，也不必依赖他高声报出身份。

行动：家族疏落地聚在场地左侧，保持轻微走动；奴仆、父亲、儿孙、发明者在约三秒内依次染色。发明者沿弧线进入人群，邻居继续走动。房屋的染色由字幕叙述，本幕没有独立房屋布景。

### 3. 一周、数月、一年 · 14 秒

不到一周，本地区的三角形和正方形纷纷仿效。一两个月后，十二边形也染了色。不到一年，风尚已传遍除最高贵族以外的阶层。一场个人尝试，开始改变共同生活。

行动：发明者穿过散落的人群，颜色从附近的三角形与方形快速接力，再传给十二边形；居民一边走动，一边陆续染色。女性与祭司保持无色。

### 4. 两代人以后 · 14 秒

两代人之内，染色风尚遍及平面国。只有女性与祭司仍不染色。颜色使相认更方便，也使聚会、诗歌和剧场成为新的生活乐趣。这段时代延续了约六百年或更久，确切的起止年份已经不可知。

行动：发明者一家退场，新的群像展开成相互穿行的街市，几位五边形居民原地轻轻摇摆。无色的女性与圆形穿过有色人群。换代通过退场和不同人物的进入表现。

### 5. 盛大的检阅 · 30 秒

军阵转过身，另一组边面迎向观看者。原著的等腰三角形由黑色底边转出橙与紫的长边，正三角形披着红、白、蓝；方形、五边形与六边形在队列间往来。颜色和转身，让观看本身成为欢乐。

行动：1,200 名三角形士兵组成 24 圈扇形，先面向指挥官，再从内圈到外圈依次转身，最后转回。方形队列旋转；五、六边形从两翼穿过。留出转身后的静止观看时间。全剧最长的欣赏段落，使用故事自己的配色。

### 6. 我们为何不平等 · 16 秒

颜色让工匠和士兵也能解决生活中的辨认问题。他们开始追问：既然我们也能看清、行动与工作，为什么法律仍把我们分在下面？有人要求取消旧式识别术的特权资助，也有人进一步要求禁止这些学问。平等的诉求与新的排斥开始交织。

行动：工匠、士兵和市民散落在领袖周围，自然走动、相遇和停顿，并持续朝向领袖；领袖来回踱步，机位随他移动，不组成笔直的阵线。

### 7. 普遍着色法案 · 18 秒

一位不规则圆形参与谋划的法案，要求女性与祭司也染色：含眼口的前半红，后半绿。在某些观察方位，两者会呈现相近的双色线段。支持者希望，同样的外观带来同样的尊重。这里展示的是提案的设想，它尚未成为已经实行的法律。

行动：一位女性和一位圆形并列，临时染色并转身示意提案，再恢复无色。观众分散在前方并轻微走动，为中间演示留出空间。画面颜色使用故事方案，字幕交代法案的原定颜色。

### 8. 三年的争执 · 18 秒

围绕法案的斗争持续了三年。一支多边形军队被人数占优的等腰三角形击败，正方形与五边形保持中立。贵族家庭也发生了致命的冲突。看似强大的联盟并不牢固，不同阶层所害怕失去的东西，也并不相同。

行动：等腰三角形从不规则站位加速推进，前方进攻者与多边形发生真实接触与击杀，其余士兵向前聚拢；方形、五边形留在两侧。家庭冲突只由字幕交代。

### 9. 一次欺骗 · 18 秒

一个等腰三角形借助颜料和伪装的声音，冒充十二边形，与一位贵族的孤女成婚。得知欺骗后，她结束了自己的生命。消息传开，许多女性因悲伤和对类似欺骗的恐惧转而反对法案。欺骗被用来反对平等；它并不能证明颜色或某一阶层天然有罪。

行动：女子与冒充者靠近，随后拉开距离；女子停留，最后退场，留下空位。外围女性陆续转向贵族一侧。不表现自伤方法。

### 10. 宣布让步 · 16 秒

首席圆形 Pantocyclus 召集特别大会。面对人群，他宣布圆形阶层愿意接受《普遍着色法案》。欢呼取代了嘘声。革命领袖 Chromatistes 被邀入中央，仿佛即将接过胜利。而他与早期同名发现者的关系一直是个谜。

行动：群众在中间通道两侧走动，领袖沿轻微弧线加速、减速后停在中央，成为全场注视的焦点；圆形留在上方。守卫散布外围，尚未封住通道。

### 11. 漫长的演说 · 16 秒

演说几乎持续一整天。Pantocyclus 逐一谈起商人、职业阶层与绅士的利益，又反复声称愿意服从多数。阵营慢慢松动，除了等腰三角形，许多人变得中立或反对。话语拖住了会场，外围的站位却已改变。

行动：正三角形、方形、五边形依次向两侧退开；女性移向外围；守卫靠近出口。领袖仍在中央，等腰三角形仍面向他。

### 12. 半小时 · 16 秒

暗号发出，准备好的袭击开始。领袖首先被杀，出口被封；近半小时，大会变成屠杀。原著的入场人数与死亡总数存在差异，但结局明确：承诺让步的会场，成了无法离开的陷阱。

行动：一位女性首先向领袖加速冲刺；守卫从两侧冲入，其他女性从上方刺入人群。被困士兵遇到阻挡、试图退避并反击；死亡由顶角接触决定，边线碎开并淡出，不再定时隐藏士兵来代替厮杀。

### 13. 一年多的搜查 · 16 秒

屠杀之后，搜查持续了一年多，深入城镇、村庄与家庭。颜色被禁用，也被禁止持有；普通人甚至不能随意说出表示颜色的词。不是一夜之间世界变灰，而是一次次检查，把颜色和敢于使用它的人带走。

行动：幸存者回到疏落、仍在走动的街市；检查队穿过人群，居民以更快的节奏连续失色。失色后继续保留走动，呈现禁色成为日常。

### 14. 漫长的无色时代 · 12 秒

此后，普通人的世界只剩形状与明暗。颜料并未从物理世界消失：制造知识由首席圆形传给继任者，生产也被严密控制。大学极高阶课程中或许仍有少量使用，但叙述者只听说过。被剥夺的，是人人接近颜色的权利。

行动：全场无色，幸存者仍各自沿弧线移动、停顿与转身，一位工匠原地轻微摇摆；圆形留在上方。取消重新排队，让观众看到禁色后的生活仍在继续。

## 史实与改编边界

- 第 1 幕制度背景来自第 3、5、6 节；第 2—5 幕对应第 8 节；第 6—7 幕对应第 9 节；第 8—14 幕对应第 10 节。
- “约六百年或更久”是整个时代的持续时间，不是距平面历 2000 年的间隔；不填写虚构绝对年份。三年斗争、近一天演说、约半小时袭击、一年多搜查分别保留。
- 十二边形不是圆形。圆形以共用几何的高边数多边形近似；原著第 11 节也说明所谓圆形实际由大量短边构成。具体离散边数仅为渲染选择。
- 早期发明者、未具名的不规则圆形起草者、后期革命领袖是不同的叙事身份；本作不补造他们的亲属关系。
- 所有群像站位、走位、时间压缩与领袖的代演形状都是舞台安排。保留原著事件，但不采用叙述者对女性、等腰三角形和不规则者的贬损作为本作立场。
- 本作没有语音；字幕承担旁白与事件叙述。房屋染色、具体骗婚过程和家庭暴力通过叙述交代。
