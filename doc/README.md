## 统一实验工作台

打开 [场景工作台](http://127.0.0.1:5173/studio.html)。这是调节规则和验证效果的 HTML 后台；正式交互与历史叙事 UI 留待实验效果确定后设计。

页面上方用同一个 Three.js 预览当前场景，黑色画面叠加人数与俯视画布宽高。四个场景始终使用相同的五个面板：

- **发光方式**：五枚可编辑主题色、独立建筑色、每位单色／主题色随机组合、染色开关、区分度增益、角色／建筑增益与曝光。选色由个体 ID 固定，不随移动或旋转重新随机；建筑默认灰紫，切换方案保持不变。
- **光线衰减**：独立开关、视野范围、衰减曲线与范围虚线。
- **散射模糊**：独立开关、散射范围、散射方式与变化曲线。
- **镜头**：俯视／居民一维按钮、观察维度、一维镜头：画面未矫正（直线接收）／画面矫正（等角展开）、FOV、一维窗口和“上下拉满”。
- **行为**：人数、接触方式、居民自由移动／静止。

房屋、色彩检阅场、星野、同心圆只提供建筑和角色的初始布局。所有面板参数跨场景共用，包括填满状态；切换只重建居民位置与生命周期，不重置配置。人数选“场景预设”时使用该布局的人数，手动选定的人数则跨场景生效。“基础实验”的角色与碰撞也在同一个右侧工作区内打开，保留左侧场景库；点左侧场景即可回来，通用参数不变。实验保留自己的动作控件，不重复显示世界场景的光学面板。

默认配置：视野范围 2,048、二次衰减；散射范围 128、二次渐变（散射开关默认关闭）；俯视、FOV 120°、一维窗口 1%；场景预设人数、触摸、自由移动；建筑增益 −7，增强方式绒面。本机对现有三种增强方式的采样函数做对照，绒面耗时最低，因此选作默认；这不是整帧性能保证。已有手动配置继续恢复，点击“恢复默认”应用这组参数。

配置在修改后 250ms 自动保存到当前浏览器的 `localStorage`，刷新或重新打开工作台时恢复。保存场景与参数，不保存临时位姿、生死或运行进度；URL 指定的场景优先于已存场景。“恢复默认”重置全部参数并保留当前场景。小窗口下五个面板依次排列，仍在同一页面。

统一度量衡：1 身长 = 成年标准体型的外接圆直径 = 1 个世界坐标长度。幼体最小 0.3 身长，成年最大 1 身长；当前观察者 0.56、同心圆标本 0.65。体型、间距、视野半径、Z 高度和坐标使用同一尺度，星野及七形状对照也使用直径 1 的标准标本。俯视比例尺随镜头缩放更新，单位本身不变；不与现实的米绑定。这里只开放尺寸范围，尚不模拟出生和自动生长。

角色、建筑增益均为 −16～+16，0 在滑条中间，每档按 `2^档位` 计算：+1 翻倍、−1 减半，−16 为 1/65,536，+16 为 65,536 倍。没有 dB 单位或小数；曝光使用 −3～+3 整数档。旧版保存的倍率恢复时归到最近整数档位，超出范围截到端点；旧的零值迁移为 −16。这是物体固定的参考值，不模拟灯光传播。“启用衰减”以观察者 XY 为圆心：光线衰减在视野范围终点降到 0%，圈外截黑。关闭衰减恢复全部距离的亮度；散射仍按自己的开关与距离生效。范围和衰减方式共同决定一条连续曲线，没有独立的遮罩强度或第二个截断距离。遮罩在曝光之后乘到成像颜色上，保留色调；无色模式同样生效。工作台强制 `fog=0`，不再使用纸白稀释和 25% 保底。亮度仍复用每个物体 128 个光照采样和材质查表。 采样纹理按物体位姿、观察者 XY 与光学参数缓存；只转头不重算静止物体，移动或改参数时才更新。真实浏览器检查中，997 位静止居民连续 12 帧的纹理重算次数为 0；复用与强制重算的画面像素一致。这减少 CPU 采样与纹理上传，不代表已经消除绘制调用或物理开销。只有启用散射才增加 GPU 图像平均，场景和几何始终只有一套。

令 `x=d/R`（R 为最远可见距离），圈外遮罩值为 0；圈内 `M=f(x)`。曲线分别为：线性 `1-x`，二次 `1-x²`，指数 `(exp(-4x)-exp(-4))/(1-exp(-4))`，平滑 `1-x²(3-2x)`。另有柔化平方反比 `(1-x²)²/(1+16x²)`，以有限中心亮度和归零终点适配本视觉模型，不是实际 Lux 测量。各曲线均从最近处的 100% 连续降到视野终点的 0%。视野范围滑条使用 `log2(距离)`，2、4、8、16 身长占相同的滑动距离，范围 2—8,192 身长；输入框可以填写非二次幂整数距离。图表与实际材质共用 `distanceAttenuation`。原独立光学研究入口保留原有对照规则，工作台使用 `attenuationMode='mask'`，固定清透成像，几何明暗由区分度增益调节；不再单列成像和辨形开关。

散射是显示特效：先由原场景深度遮挡确定可见颜色，再用观察者距离决定平均宽度。“散射范围”独立于视野范围，从中心清晰过渡到边缘最大模糊，超过该距离保持。删除散射百分比；“散射方式”选择平滑、线性、二次、指数或对数，只改变范围内的渐变节奏。面板以保留清晰度显示：近处 100%，范围边缘 0%；内部平均半径仍从 0 增至固定最大值 12 CSS 像素。二次清晰度为 `1-x²`，与二次衰减同形。关闭散射开关完全旁路后处理。单独开启散射不乘亮度衰减、不设可见截断；两个开关同时开启时既变暗又变模糊。GPU 使用原画面和深度纹理，俯视横向、纵向各平均一次，一维只横向平均，保证上下拉满仍是相同颜色。近处边界保护抑制远处颜色越过前景，范围虚线等辅助标记单独保持清晰。关闭散射会释放缓存的画面纹理。视野范围只用于亮度衰减及可见边界；散射范围只用于模糊的远近变化，两项都使用 2—8,192 身长的倍数滑条和数值输入框。旧浏览器配置缺少散射范围时，仅在首次读取时采用原可见距离作为初始值，保存后两项独立。它不是体积雾或严格的眼睛成像模型。

小地图去掉“角色位置”、重复人数及视角说明。右下角只有“锁定北向”开关：开启固定北向，关闭跟随观察者转头，旁边的小字显示当前状态；该选择随共用配置自动保存、跨场景恢复。

场景库新增“星野”与“同心圆遮罩”。星野以 240 位共用 Character 刚体构成近邻、中距离居民和远方聚落，复用世界渲染与所有面板；不再在工作台加载独立的 Canvas 光学实验。星野分布在 4—24、24—128、128—1,200 与 1,200—3,000 身长区间，近处稀疏、远处仍有聚集，初始个体间隔超过 2 身长。独立光学对照仍保留原有纯远景标本。同心圆场景复用原 3D 世界：40 圈半径 5—200 身长，每圈人数随半径增加：内圈 6 位，第 20 圈 24 位，最外圈 48 位；相同尺寸和配色的静止正五边形，圈间交错角度降低遮挡；共 996 位标本，默认俯视完整容纳实际布局。所有场景都标明“俯视画布 宽 × 高 身长”，不再混用布局宽高、半径或直径，文字不拦截画面点击。关闭视野遮罩即可查看全场，重新开启仍用原范围；没有重复的全场对照按钮。观察者可移动以检查遮罩随视点更新。开启“显示视野范围”可在俯视图显示虚线圆，圆心与观察者一致，半径与遮罩一致；两侧及中央方向线截止圆周。关闭遮罩时没有有限边界圆，方向线只覆盖当前画面。辅助圆不参与光照、碰撞或居民视野。

俯视画布的“缩放至合适”根据当前墙体与角色真实顶点计算包围矩形，留 8% 余量后适配窗口比例。首次加载、切换场景和修改人数重新适配；从俯视下降时，取景中心连续从场景中心移向观察者，保留当前缩放，不再起步就跳到观察者中心；可用画布滚轮或左下角按钮放大缩小（25%—1,600%）。缩放独立于居民 FOV，不改变体型、光学距离或行为参数，也不跨场景保存。宽高取实际俯视镜头在世界平面上的覆盖范围，包括空白区域；居民视角仍明确标为“俯视画布”。直接打开独立角色或光线实验页面时仍提供左侧返回链接；从工作台进入角色实验则始终保留工作台左侧导航。

实体基础高度固定为 0.05 身长，围绕 Z=0.032 对称；旧配置的高度字段不恢复。镜头先降到 0°，然后在 300ms 内，把同一批几何的投影高度连续展开到“一维窗口”目标。始终使用原 canvas 的完整缓冲区；没有终点换层、一像素缓冲区或 CSS 拉伸。

“一维窗口”范围为视口高度的 1%—100%，工作台默认 1%。窗口外自然为空黑；“上下拉满”把同一个投影高度变到 100%，每列上下颜色一致，实体尺寸和碰撞不变。填满时调节窗口会收回到所设高度。切回俯视先还原投影，再旋转镜头；保留系统减少动态效果偏好。平面透视按视线斜率接收，曲面等角按水平角度接收；方向点击与镜头使用相同规则。矫正后的等角展开使静止物体在匀速转头时匀速出画；平移仍受距离影响。曲面投影逐片元求当前边界的实际距离并写入深度，避免把线性透视深度错误用于角度投影。所有二选一设置均为并排按钮。

俯视时右下角显示观察者的一维视野，进入居民视角则换成位置小地图。视野小窗跟随观察者位姿、一维镜头、FOV、窗口高度和全部光学参数。它在同一 WebGL 画布上增加一个小视口绘制，复用同一场景、网格和光照纹理；不复制物理世界、不重新积分光学，散射开启时同样应用距离模糊。观察者自身、俯视描边和辅助线通过相机图层排除；下降途中关闭小窗。

染色与灰度都启用几何深度的显示增强，复用 `boundaryLighting` / `surfaceLight` 已有的最近点、尺寸归一化和局部深度对比。亮度随实际表面到眼睛的距离改变，旋转时近亮远暗的分布也改变，不固定“头白尾灰”。全局遮罩控制远处是否可见，局部对比保留一身长内的深度差；这是原书启发的显示补偿，不是严格的单一雾衰减。“区分度增益”范围 0～+3，默认 +1。0 完全关闭增强；锐利方式在正值时对局部对比使用 `D^(2^档位)`，近处参考点保持 1，增大档位使后退部分更暗。角色和建筑共用该规则；建筑各墙段共享整栋的最近距离与尺寸基准，避免每段墙各自归一化到最白。“显示染色”只决定是否使用物体配色；区分度增益开启后作用于亮度，保留配色色相，与染色开关独立。旧配置的负区分度档位迁移为 0，其他参数保留。增强方式默认“绒面”，压低亮峰并保留宽缓层次；“柔和”通过平滑曲线扩大亮部、放缓过渡；“锐利”保留原先的集中亮峰。这些是显示增强曲线，不增加光源、毛发或新的几何。三种方式在 0 档都完全关闭。

“头白尾灰”是独立的定向配色方案，使用头部白、中段灰、尾部深灰三个可编辑色值，随身体转动；不替代几何深度增强，两者可同时生效。自定义方案保存五个主题色，或定向方案的三个色值与用途；建筑色独立保存。旧的三组头／中／尾色迁移成主题色，旧场景行为配置迁入一套共用参数。已删除的成像、辨形、粒子与额外高度字段不恢复。

入口 `studio.html`，配置与布局位于 `src/studio.js`、`src/studio.css`。四个场景都通过 `src/studio-bridge.js` 使用 `src/main.js` 和 `src/world.js`；独立研究页仍保留。
## 三个实验室与技术选型主线

项目通过光线、角色、房间三个实验室分别验证基础能力，再结合实验结果决定复杂场景的呈现方式。当前主会话负责基础技术选型与跨实验室整合；各实验室使用独立 session 演进。

核心目标是还原《平面国》颜色革命的历史。三个实验室服务于这一历史体验所需的角色、光照、空间和观看方式验证；后续统一收进网站的调试台入口。实验能力和调试界面围绕这个目标推进。

| 实验室 | 核心问题 | 当前起点 |
| --- | --- | --- |
| 光线实验室 | 居民看见什么：一维投影、遮挡、亮度衰减、辨形、亚像素光点及染色 | Study 000；在独立 session 中演进 |
| 角色实验室 | 角色自身的形状、动作、碰撞、受伤和死亡；先手动驱动 | `character-lab.html` 与 `src/characters.js`；自主运动暂不实现 |
| 房间实验室 | 墙与门洞、房间布局、角色放置、世界推进与观察视角 | Study 001；组合共用 `Character` 实例与 `optics.js` 光照 |

实验室是研究方向，Study 是具体实验。一个实验室可以逐步增加多个 Study；现有编号和入口保留。

### 当前技术基线

- 几何与运动发生在二维平面；碰撞主体保持刚性，角色状态由共用 `Character` 定义。
- Rapier 2D 用于碰撞与运动。角色实验室在 `Character` 中定义手动运动、碰撞响应与生命周期；房间提供物理世界，放置角色并推进时间。
- Three.js 已用于房间原型的俯视、镜头过渡与居民视野呈现。光线实验室使用 Canvas 和独立的一维成像计算，便于比较光学规则。
- Study 000 与 Study 001 共用 `src/optics.js` 的成像函数和 `OPTICS_RULES`。摄影棚只转换世界轮廓、材质名和观察者位姿；辨形增强属于共用光线规则中的视觉辅助。

### 实验结果如何进入主线

每次实验记录：要验证的问题、采用的规则与参数、可复现的场景、观察结果、适用边界，以及是否建议成为共用能力。主线据此保留或调整技术选型。

跨实验室整合首先对齐四类信息：居民的二维轮廓与位姿；运动更新后的实体状态；接触、受伤、消亡等事件；可见边界的光学属性。角色实验室定义角色本身的形状、动作和生命周期；房间实验室放置实例，推进世界并把接触事件交给角色；光线实验室定义房间中的观察者如何根据角色与世界状态形成视野。角色实验室不计算发光、光照或观察。角色实例数量与单个多边形边数分别表达；犯罪系数的含义及其行为影响待实验确定。

下一步的整合目标是一个小闭环：居民在房间里移动，受到墙与其他居民约束，观察者的视野同步反映其运动、遮挡和状态变化。先通过这三个实验室验证闭环，再决定更复杂的人群、叙事与视觉表现。

## 角色实验室 · 形状、动作与碰撞

打开 http://127.0.0.1:5173/character-lab.html 。上方用同一比例展示六种角色。`Character.size` 是外接参考圆的相对直径，范围 0.3～1 身长，默认 1；所有类型共用这个范围。女性线段等于参考圆直径，正多边形与狭长三角形的顶点都在圆上。这里使用归一化比例，浏览器不按英寸画图；显示缩放与角色实际尺寸分别控制。

每个角色的头部位于局部 +X 方向，并在预览中标亮。女性的后半段用虚线表示尾端，前端用亮线标出；这是角色实验室的方向示意。原书第四节描述眼口一端较亮、从背面观察时尾端近乎不可见，真正的观察结果由光线实验室计算。女性全长保留线段碰撞体，虚线空隙不改变碰撞，SVG 使用 `vector-effect="non-scaling-stroke"` 保持 1 CSS 像素线宽。

居民沿头部轴线对称染色，轴线两侧的对应边同色，从头部暖色过渡到尾部冷色，内部保持空心。三角形两条头侧边暖色、底边冷色；正方形两条头侧边暖色、两条尾侧边冷色；正五、六边形在两侧加入中间色段。女性头暖尾冷，尾部在角色预览中仍为虚线。此为借用原书分段染色方式制定的实验配色。

`src/paint.js` 定义杜菲、清透柔和、霓虹、莫兰迪和自定义方案，每种方案五枚主题色。默认每位居民使用一种主题色，也可稳定组合这些色块。`paintVariant` 使用实例 ID 的稳定散列，切换方案或转身不会重新随机；构造参数可指定样式和变体。`setPaintStyle(id)` 只改染色，不修改形状、位置、运动或生命状态。建筑采用独立的共用灰色，默认偏灰紫。

`Character.paintedEdges` 返回局部坐标下的 `[{a, b, color}]`，房间和角色预览共用这份数据，颜色随身体转动；女性分为两个染色区段，原有 `vertices` 和碰撞体仍是一条完整线段。角色只定义染色，距离、遮挡及着色开关由光线与房间实验室处理。

下方选择两个实例，可分别调整体型，调整后重置实验。W / 上箭头沿头部朝向前进，S / 下箭头后退，A D / 左右箭头原地转向，Q E 向头部左右两侧横移，也可按住页面按钮操作。前后与横移组合时限制总速度，避免斜向移动更快。角色没有自主运动；页面默认放大展示，角色的大小不会因为朝向改变。

`src/characters.js` 是本实验室的角色基准：`Character` 保存类型、实例属性、形状、接触和生命周期，并提供 `attach(world, pose)`、`move({forward, side, turn})`、`setInteraction(mode)`、`onCollision(other, started, initiator)`、`injure()`、`die()`。页面只负责输入、绘制、推进 Rapier 并转发接触事件。每个角色保存自己的“击杀 / 触摸”方式，默认击杀；按钮只切换方式，随后需要移动或转向靠近对方。接触事件明确传入本步由用户驱动的主动方。击杀必须由主动方自己的多边形顶点或线段端点撞中对方，只有被撞方死亡；主动方侧边撞到对方顶点也不会击杀。触摸与非尖角接触都会使双方停住并存活，允许向远离接触面的方向移动或转向。贴着对方切换为击杀后，仍需再次用尖角或端点向对方运动才执行击杀；静止的被撞方不会因自己选了击杀而反杀。边界仅阻挡移动。死亡停用身体并保留淡色轮廓，界面直接显示两个角色的生死状态。犯罪系数与阶级保持 `null`。

`hitsWithCorner()` 读取 Rapier 碰撞检测阶段整组局部接触点，按接触距离选取最先接触的一组；只有这些点对应主动方同一个顶点或端点才算尖角命中。这样两条边贴合时，即使引擎报告边的两个端点，也不会当成尖角击杀。顶点匹配容差为角色尺寸的 0.0001 倍。`approaches()` 使用当前运动意图，连同转动时接触点的扫动速度，确认是在撞向对方而非正在移开。这一版不按角度大小区分伤害。

线段碰撞体使用实验质量 1 和转动惯量 `length² / 12`；多边形也使用质量 1。参考 [Rapier 质量属性说明](https://rapier.rs/docs/user_guides/javascript/collider_mass_properties/)。[《平面国》第三、四节](https://www.gutenberg.org/files/201/201-h/201-h.htm)是尺寸比例与女性头尾的参考；击杀与触摸采用上述实验规则。Study 001 已直接复用本类、几何、运动与接触规则。

运行 `node tests/verify-characters.mjs` 验证统一尺寸范围、按头朝向运动和横移、斜向速度、原地转向、尖角与侧边区分、线段头尾端点与旋转撞击、回调顺序、触摸停住与后退、接触时切换方式和死亡身体停用。页面不包含光学计算或自主控制。

## Study 000 · 形状与视野

打开 http://127.0.0.1:5173/study-000.html 。三角形、四边形、五边形、六边形、七边形、线段和圆形并列展示，各自配一位观察者与一维视野。共用旋转和距离控制，默认自动旋转；手动拖动角度会暂停。距离统一按身长计，范围 3—3,000 身长，支持“近处 / 远处 / 一个光点”定位。线段长度为 1 身长，没有物理厚度；圆形半径为 0.5 身长，以 256 段边界近似，旋转时保持相同轮廓与投影。俯视图按比例容纳居民和观察者，因此远处的轮廓也会缩小。

默认边界发光、空处纯黑、雾极淡。整体亮度和雾可独立调整；七个投影以及下方星野共用同一份光线规则。星野有 240 个互不重叠的静态居民，位于 1,200—3,000 R，所有居民采用相同的居民材质，不再随机分配个体亮度。可拖动、使用方向键或朝向滑条转头，比较密集和稀疏方向。关闭“显示居民”可验证纯黑空视野。

默认另启用**观察者中心的接收衰减**，距离 `d` 是实际表面点到当前观察者 XY 的绝对世界距离。共享规则 `attenuationDistance=10`、`attenuationFloor=0.25` 定义接收遮罩 `T(d)=0.25+0.75/(1+(d/10)^2)`：距离为 0、10、25 时分别保留 100%、62.5%、约 35.3% 的接收亮度，继续远离时平滑趋近 25%，保留远处星点。它没有硬截断，也不会按每个对象的最近点重新归一化。这是独立旧光学对照的显示规则；统一工作台改为有限半径、最远处归零的遮罩。

“衰减距离”可调整 1—100 个世界单位；数值越大，同距离处越亮。关闭“启用接收衰减”等价于 `rules.attenuationDistance=0`，可对照原始星点或进行无接收遮罩的几何验证。运行页面的标本直径为 1 身长，距离直接按身长显示；光学测试函数仍可显式指定任意半径。“整体亮度”控制观察端曝光，不修改材质的本征发光；“雾的浓度”仍独立控制介质透过率 `exp(-fog*d)`。接收遮罩在曝光之后生效，避免高曝光把近远差异冲掉。

默认开启可关闭的“辨形增强”：按每个可见位置相对该对象最近边界的真实距离加强明暗，以面积质心到最远顶点的距离归一化；正多边形时等于外接圆半径。最近点可在边中间，旋转时随几何移动。同一条边内也会按距离连续渐变。显示对比度使用 `0.45 + 0.55 × exp(-3 × 相对距离)`，从最近点开始连续下降。它在曝光与 sRGB 转换后应用，避免不同距离的光量被高曝光压成同样的白色；较远部分最低保留同材质未增强显示亮度的 45%。这是显示对比度下限，实际光量仍按雾与像素覆盖率计算。这是额外的视觉辅助，不能解释为均匀雾的物理定律；当投影由 8 像素缩到 1 像素时平滑减弱，亚像素光点不受增强影响。关闭可对照原始发光模型。

Study 000 与摄影棚默认使用“清透柔光”，各自的成像选择器可对照“哑光”和“原始”。三种效果调用共用的 `rules.finish` 显示选项：`clear` 连续提亮中高光，避免哑光压亮部造成的灰感，暗部仍有层次；`matte` 保留上一版压柔亮部的曲线；`original` 使用原始曲线与光晕。清透曲线对显示亮度 `b` 使用 `b + 0.75 × (max(0, b − 0.2) / 0.8)² × (1 − b)`，全程单调，低于 0.2 的暗部与微弱星点保持原值，也不改变黑白端点。所有色彩在统一曝光后乘色调。两种柔光模式都让 8 像素以上的清晰轮廓不向外扩散光晕，1 像素以下的光点保留扩散，中间平滑过渡。它们是成像风格，没有引入透明、折射或金属反射；真实边界、遮挡、本征发光及远近排序均保留。共用库默认值仍为 `OPTICS_RULES.finish='original'`，两个页面显式选择清透效果。

`src/optics.js` 先把边界投影到一维屏幕，按投影端点划分可见区间，取最近遮挡并累计每个像素内的可见覆盖率。小于一个像素的居民仍贡献光；同一像素内不同可见区间的光相加，完全遮挡的居民不贡献光。随后用归一化的一维光学扩散、统一曝光与 Reinhard 映射生成灰度图像。空处不补光，图形没有强制最小宽度，真实投影和光晕宽度分开处理。`src/study-scene.js` 只生成演示多边形和人群；`src/study.js` 同步控制和绘图，`src/study.css` 为页面样式，不加载物理引擎。

### 共用光线接口

角色与行为更新 → 世界坐标下的二维轮廓及材质名 → 统一光线规则 + 观察者 → 一维光量 → 显示像素。

- **角色与场景提供** `{material, vertices}`：`material` 引用居民、房屋等共用材质，`vertices` 是按边界顺序排列的世界坐标点。不传角色自己的发光强度、衰减系数或辨形参数。形状、角色身份和行为不会选择另一套光线算法。
- **全局规则** `OPTICS_RULES`：`materials` 统一定义每种材质的本征发光强度；`fog` 控制介质透过率；`attenuationDistance`、`attenuationFloor` 控制观察者中心的接收遮罩；`contour`、`contourFloor` 控制独立辨形提示；其余字段控制曝光和光晕。当前居民材质为 1；房屋材质暂定为 0.5，仅是待房间实验验证的参数。新增材质必须显式加入规则；学校、水等尚未设定，透明或折射效果也尚未实现。相同发光能力仍会因几何、距离和遮挡而呈现不同亮度。
- **观察者提供** `{x, y, heading, fov}`：朝向 0 为世界 +Y，正角朝 +X 转动，角度使用弧度。每个观察者的位置可以不同，同一场景传入同一份 `rules`。

```js
import {OPTICS_RULES, projectScene, exposeRow} from './src/optics.js';

const rules = {...OPTICS_RULES}; // 场景共用，演示控制只修改这一份
const boundaries = [{material:'resident', vertices:[{x:-1,y:6},{x:0,y:5},{x:1,y:6}]}];
const observer = {x:0, y:0, heading:0, fov:Math.PI/2};
const projection = projectScene(boundaries, 800, {observer, rules});
// light = 可见本征光量 × 介质透过率；contrast = 接收遮罩 × 辨形提示。
const pixels = exposeRow(projection, rules); // RGBA，800 × 1，可供 Canvas 或 Three.js 使用
```

模块不依赖 DOM、Three.js、Rapier 或角色类，也不修改输入。轮廓可为两个端点描述的非零长度线段，或非零面积、无自交的封闭多边形；对象之间须不相交，调用方排除观察者自己的身体。曲线目前需要先离散为多边形。默认光线输出为灰度；房间可通过 `rules.coloring` 启用实际可见边的染色。`paintedEdges` 仅提供边界分段和色调，本征光量仍取自共用材质规则。Study 000 使用此接口，Study 001 保留它作为独立光学对照。`src/sight.js` 将刚体局部轮廓变换到世界坐标，居民统一引用 `resident` 材质，墙体引用 `house` 材质；排除观察者自身和已移除角色。固定墙体采用真实碰撞厚度，在墙体交点补充共线顶点，使每个投影区间的遮挡次序稳定，并保留完整墙体轮廓用于辨形尺度计算。

这里是直达光与均匀介质衰减的教学模型，不计算反射或散射入光。可见性区间算法要求实体边界互不相交；每个像素片段内的亮度采用中点近似。星野的密集方向更亮，是这组相同尺寸、相近发光强度和距离的居民的结果，亮度并不普遍等同于人数。

光线实验室单独运行 `node tests/verify-optics.mjs`：验证 0—25 世界单位的距离明暗、高曝光下的区分、本征发光与介质独立、辨形独立、房屋分组、观察者位姿、亚像素星点、遮挡与五边形灰度。摄影棚的联合验证仍由 `tests/verify.mjs` 负责。

- 房屋的 38 段墙属于同一个光学对象，共用整座房屋的最近边界与轮廓尺度，不再让每一小段墙重新从最亮点开始。`src/sight.js` 的 `houseBoundaries` 向俯视与居民投影提供同一组墙体；共享的 `object.outline` 仅用于辨形尺度，`object.boundaries` 是实际墙体边界，门洞与遮挡仍按各墙段真实轮廓处理。房屋分组只决定辨形基准；接收衰减始终按表面点到观察者的绝对距离计算。
- 所有居民都是角色实验室的 `Character` 实例，使用六种已定义类型和 0.3～1 身长 的体型。女性在俯视图、小地图、碰撞和居民视野中都使用两个端点描述的线段；方向示意不额外改变光学亮度。小地图显示角色轮廓和位置，观察者居中，可切换“北向固定 / 朝向跟随”。“居民”可切换 14、100、300 个实例，工作台默认让居民静止，开启“自由移动”后游走；关闭击杀时，遇到墙或角色后退开换方向，观察者仍由用户控制。
- 工作台“是否击杀”（是 / 否）控制观察者，“居民是否击杀”（是 / 否）控制 NPC，各自保存、互不改写，均默认否。击杀仍需主动方的尖角或端点命中，侧边只接触。新生成居民继承设置。死亡立即停用物理身体并从小地图移除；“击杀动画”默认关闭，关闭时形状直接消失，开启时复用原有边散开、淡出，600 毫秒后完全消失。系统减少动态效果时直接消失。
- 已移除自动生成角色的“尖角碰撞”演示及其定时驱动逻辑。触摸与击杀仍由 `Character.onCollision` 判定；“原图对照”可以打开提供的示意图。

右上“场景”可切到色彩检阅场，也可直接打开 `/?scene=parade`，再切回房屋基准。检阅场初始布置范围 116×76 世界单位（不设隐藏围栏），提供 1000/2000 位居民（包含观察者），每位仍是独立 `Character`。两侧队列保留中央通道、分区横道和错列间隙；默认暂停自由移动以便观察，开启后继续用原有游走和碰撞。场景切换重新建立该场景；不保留上一场景的临时位姿。这里是规模与色彩观看实验，尚未编排完整历史事件。

## 阅读路径

1. `src/characters.js` → `src/world.js`：前者定义角色，后者建立 38 段墙、放置 14 个初始实例，负责安全放置、输入与演示脚本、推进世界、转发带主动方信息的碰撞事件。房间不另写角色轮廓、运动速度或死亡判定。
2. `src/main.js`：同步物理位置到同一份 Three.js 网格，控制摄影机与小地图。材质调用 `src/optics.js` 的 `boundaryLighting`、`surfaceLight`、`exposeLight`，按片元到观察者的二维距离读取 128 点明暗纹理；工作台遮罩乘到最终颜色上，并在片元处保证最远距离之外纯黑。居民视角仍绘制这些网格，空白方向直接显示黑色背景。`src/sight.js` 提供坐标、视线方向、墙体分组和配色工具；其中 `createSight` 仅保留用于独立光学对照与验证，房间渲染不再调用。
3. `src/style.css` 与 `index.html`：覆盖在场景上的控制面板、房间标签与原图弹窗。

“开启着色”和“配色风格”只修改外观，不重建世界、不推进物理，也不改变运动或生死。`src/sight.js` 的 `setScenePaintStyle` 更新角色样式和墙材质颜色；已有 mesh 只更新 `paint` 属性，新 mesh 使用当前方案。切换保留每位居民的变体编号，霓虹也不额外提高曝光或光晕。俯视、居民镜头与小地图同步切换。俯视的角色边界使用 2 CSS 像素描边以保持可读，包含女性线段；描边宽度不进入物理或居民视野的遮挡几何。

物理以固定 1/60 秒推进，使用连续碰撞检测和微小接触间距。离开完全俯视后隐藏观察者自身及其光圈；返回俯视恢复。每帧只绘制一次世界几何，下降只改变摄影机；没有独立的一维画面或中央带裁切。

## 验证与边界

```sh
npm test
node tests/verify-characters.mjs
node tests/verify-optics.mjs
npm run build
```

浏览器打开 `http://127.0.0.1:5173/tests/verify-render.html`，运行实际 WebGL 检查：下降隐藏自身，先旋转再展开一维窗口，窗口外纯黑；上下填满不改变实体、各行像素完全一致、窗口尺寸变化自动填满；最低增益的实际 RGB 接近零，自定义颜色进入实际材质。还检查五面板、分类增益、有限距离遮罩、俯视单击行走、居民单击转向与双击瞬移、行为设置、自定义配色跨场景和刷新恢复。

`tests/verify.mjs` 实际运行 Rapier，验证摄影棚共用角色实例、六种类型与尺寸、女性线段碰撞体、外墙阻挡、门洞通行、拒绝墙内放置、尖角击杀与死亡停用、300 个实例的游走与暂停、视线忽略自身和数量切换清理。300 步后的穿透检查采用 0.001 身长阈值；这不是任意状态或连续时间下的数学零穿透证明。构建会提示包含 WASM 的包较大，原型压缩传输约 1 MB。

`createSight` 的光学对照检查验证与光线实验室默认输出一致、不同宽度、朝向和平移转换、移除角色、远处亚像素光量及墙体遮挡。另在五个朝向下，以每像素 128 条 Rapier 射线独立对照房屋几何；关闭接收衰减、辨形与光晕，雾系数为 0.1、曝光为 1，允许最多 2 个灰度级的积分差异。这些验证针对光学库，不代表当前 3D 摄影机逐像素等价于一维积分模型。

接收衰减另以距离 1、3、6、12、24 的相同发光边界检验：关闭辨形增强时依然近亮远暗，俯视采样与居民中心像素一致；固定物体、移动观察者得到相同的距离序列。旧亚像素守恒与局部辨形测试显式关闭接收遮罩，避免把不同效果混在同一个断言中。

额外检查把小光源放在视角边线、中心、内部和外部，并在六个朝向下核对它落到预览的对应列；也验证居民视角的瞄准指令不移动位置、房屋各墙共用明暗基准，以及一个物体拆成多个边界片段后与完整轮廓成像一致。

`verify-optics.mjs` 另验证可见边的分段配色、低饱和灰蓝墙、灰度关闭路径、曝光与距离下的色相、遮挡不漏色及亚像素混色；摄影棚检查着色切换前后的像素恢复和位姿/生死不变；另验证各主题的稳定变体、往返还原、光照参数不变、灰度状态下选择与重新开启，以及新增居民继承当前风格。

Study 000 额外验证七种形状的透视与旋转、亚像素覆盖率随横移守恒、同像素内可见光累积、前排遮挡、纯黑空视野、240 位居民不相交，以及转头后的疏密和光量差异。`npm run build` 输出首页跳转与统一工作台、房间、角色、光线实验入口；测试页与文档不发布。

摄影棚不再使用旧的凹陷和碎片崩解效果；受伤与死亡以角色模块状态为准，不修改真实轮廓。Three.js 负责所有房间视角的几何投影与遮挡，共用光学库提供表面明暗；独立光线实验室另做一维积分和光学扩散。游走和用户操作全部复用 `Character.move`。工作台配置保存于浏览器本地，无服务端或仿真进度持久化。
